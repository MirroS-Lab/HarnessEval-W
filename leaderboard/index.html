03

Submit

Upload a JSON file, paste JSON directly, or submit a ZIP containing leaderboard_submission.json at the root. Accepted submissions are saved to the backend pending queue and are not added to the public leaderboard automatically.

Review flow

Required JSON keys are model_name, model_link, model_type, and one overall score field. ZIP uploads must place leaderboard_submission.json at the ZIP root.

Overall can be provided as overall, total_score, total_m_score, or scores.overall. Scores should use the 0-100 scale shown on this leaderboard.

The backend stores accepted submissions under submissions/pending/. Verification outputs can be included under verification/ in ZIP uploads or referenced in notes.
